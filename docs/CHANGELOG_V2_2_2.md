# v2.2.2 修改记录（课表导入流程返工）

- **应用名称**：桃课
- **版本**：Android `versionCode 6` / `versionName 2.2.2`（Debug 包 `2.2.2-debug`，包名 `com.campus.timetable.debug`）
- **完成日期**：2026-11-27
- **起因**：用户反馈「导入课表这方面不合格」。在雷电模拟器复现后确认：
  1. 选择「示例树维高校（如清华大学等试点样例）」后，按钮打开的是**教务处网站首页**（`jwc.eams.edu.cn`），而不是真正的教务系统登录页；
  2. 在该首页点「提取课表」必然失败，而且**受控浏览器会直接关闭**，用户刚登录的会话被丢弃；
  3. 失败提示只说「网页结构不兼容」，没有告诉用户「先登录、再进入学生课表」；
  4. 网页解析器把页面上**所有表格**拼接在一起，导航/新闻表格也会被当成课程；跨行/跨列单元格会导致课程错位；纯文本兜底会把首页零散文字识别成假课程。
- **许可**：CC BY-NC 4.0，**禁止任何形式的商业使用**（见根目录 `LICENSE`）

## 一、流程修复（用户可感知）

### 1. 学校入口改为真实教务系统登录页
- 示例树维高校（如清华大学等试点样例）（代码 `4100000001`）目录项改为：
  - 教务系统入口：`https://jwxt.example.edu.cn/eams/localLogin.action`（URP/EAMS 登录页，标题「示例树维高校（如清华大学等试点样例）教学管理系统」，公开访问核验）；
  - 教务处网站：`https://jwc.example.edu.cn`（保留为「打开教务处网站」）。
- 学校卡片同时显示「教务系统入口」和「教务处网站」，并提供两个独立按钮，不再让用户从教务处首页自行寻找入口。
- 目录更新逻辑修复：`ensureDefaultSchoolCatalog()` 现在会比较内置目录与数据库差异，**应用升级后也会应用新的入口地址**（此前只在首次安装时写入，老用户升级后仍是旧地址）。

### 2. 提取失败不再关闭浏览器
- 仅在识别成功时才关闭受控浏览器并进入预览；登录页、动态页、无法识别页都会**保留 WebView**，会话与已登录状态不丢失，用户可继续登录或切换到课表页后再提取。
- 提取期间按钮禁用并显示进度条，避免重复点击。
- 失败信息改为可执行的指引，并附诊断数量，例如：
  > 未在当前页面识别出课表：已检查 1 张表格与页面文本，未发现「星期 + 节次 + 周次」的排课结构（编码：UTF-8）。如果您仍停留在教务处首页，请先登录教务系统并打开「学生课表 / 本学期课表」页面后再点「提取课表」……

### 3. 登录页识别提示
- 在教务登录页点「提取课表」时提示：当前页面仍是登录页，请先在页内完成登录与验证码，进入「学生课表 / 本学期课表」后再提取；并再次声明不保存、不拦截密码。

## 二、网页课表解析器加固（`school-adapters`）

| 问题 | 修复 |
|---|---|
| 页面所有表格被拼接，导航/新闻表格混入课程 | 只采用候选课程最多的一张表（旧 URP 适配器同步修改） |
| `rowspan`/`colspan` 导致星期错位 | 新增 `expandGrid()` 将表格展开为二维网格，按展开后的列号映射星期；跨行课程格只解析一次并保留完整节次范围 |
| 纯文本兜底把首页文字识别成假课程 | 仅当页面同时具备 ≥3 个不同星期、节次、周次特征时才启用自由文本解析 |
| `parseGridCell` 把「课程名 + 空行 + 周次」拆成两门课 | 纯周次/节次/教师/教室行并入上一门课，不再单独生成课程 |

新增 4 项回归测试（`SchoolAdaptersTest`）：
- 教务处首页（含零散「星期一/第1节」文字）必须返回失败而不是假课程；
- 跨列星期表头下，三门课分别落在周一/周二/周三；
- 跨行课程格只出现一次且节次范围正确；
- 多表格页面只取最像课表的一张。
