## 二、因外部凭证/实网权限尚未完成的部署配置项

以下项目代码逻辑与接口均已完备，但因缺少真实商业账号、学校实测账号或物理设备环境，上线前需由部署方补齐配置：

1. **生产短信验证码服务商凭证（阿里云 SMS）**
   - 现状：`SmsDispatchService` 已隔离开发/生产环境，`prod` 环境严格禁止 `debug_log`，缺少阿里云参数时返回 `503` 提示。
   - 剩余工作：企业实名认证开通阿里云短信，在 `.env` 填入真实 `ALIYUN_SMS_*` 参数并在 `SmsDispatchService` 启用正式 HTTPS 发信网关调用。
2. **和风天气 QWeather 商业 API Key（可选）**
   - 现状：客户端默认已接入免密钥真实的 **Open-Meteo** 气象与 AQI 服务可直接运行；`QWeatherProvider` 与后端 `/api/v1/weather/proxy` 完整实现，未填 Key 时明确报错提示。
   - 剩余工作：如需切换至和风天气，申请专属 API Host 与 Key 并写入 `.env` 或 `android/local.properties`。
3. **具体高校教务系统实网验证**
   - 现状：目录已收录教育部 2741 所大陆高校，正方/强智/新 URP/旧 URP 四类通用适配器与受控 WebView 已就绪；但遵循「未经实际验证不允许标为已支持」原则，目录中**已验证学校为 0 所**（通用适配 37、辅助登录 42、暂未适配 2662）。
   - 剩余工作：针对目标高校使用真实在校生测试账号完成官方登录与实网课表提取验收后，再将该校 `verified` 置为 `true`、`supportStatus` 置为 `VERIFIED` 并登记验证时间；学校目录支持远程热更新，无需重新发版。
4. **手机系统/厂商天气入口（v2.1.0 已按需求删除）**
   - 现状：已移除系统天气探测、打开入口与 `SYSTEM_VENDOR` 数据源，天气仅使用 Open-Meteo 与和风天气。旧设置升级后自动回落 Open-Meteo。
   - 剩余工作：无。若未来厂商开放公开 SDK/API，可新增独立 `WeatherProvider` 实现，但当前不再提供该入口。
5. **Release 正式签名证书与真机/ROM 实测**
   - 现状：本次交付可直接安装的 Debug APK（严禁伪造正式签名包）。v2.2.1–v2.2.3 已在雷电模拟器 LDPlayer14（Android 14）完成逐页实机验收并累计生成 29 张截图（`docs/screenshots/`），覆盖课表、导入、教务处直达、受控浏览器步骤横幅/电脑模式/横屏/帮助、天气、节假日同步、作息规则、小组件中心与备份页。
   - 剩余工作：生产发布前配置企业正式 Keystore 签名；在物理真机与国产 ROM 实测闹钟响铃/重启恢复、ML Kit 首次离线模型初始化、4 种小组件实际拖拽与刷新、MIUI/ColorOS/OriginOS/HarmonyOS 后台保活策略；使用真实教务账号完成校内网络登录与课表抓取验收。
