## 一、受控教务浏览器（用户可感知）

| 改动 | 说明 |
|---|---|
| 全屏浏览 | 浏览器打开时隐藏应用底部主导航，避免「导入」高亮让人误以为仍在导入页，也为横屏留出高度；关闭后自动恢复 |
| 步骤横幅 | 始终显示「请找到个人 / 学期课表」+ 三步操作提示；识别失败时同一位置变红「尚未找到有效课表」并显示具体原因 |
| 电脑模式 | 切换桌面版 Chrome UA 并刷新，适配只在电脑版渲染的教务系统 |
| 横屏模式 | 一键转横屏，宽表课表更易查看；退出页面自动恢复原方向（MainActivity 增加 `configChanges`，旋转不重建、不丢会话） |
| 横屏收起地址栏 | 进入横屏时自动收起 URL 输入行，把有限高度让给网页；底部「地址」按钮可随时展开 |
| 打不开帮助 | 汇总三条出路（电脑模式+横屏 / 系统浏览器打开 / Excel-PDF 或提交适配申请），并支持「复制链接」 |
| 入口文案校准 | 入口 URL 不含登录/系统特征（`login`、`jwglxt`、`eams`、`jwxt`、`urp` 等）时，按钮改为「打开教务入口」，并提示先点「教务系统 / 学生登录」；不再把教务处首页冒充登录页 |
