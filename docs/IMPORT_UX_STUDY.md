# 竞品导入流程研究：WakeUp 课程表

- **研究日期**：2026-11-27
- **研究对象**：WakeUp 课程表 6.7.6（`com.suda.yzune.wakeupschedule`，versionCode 564）
- **获取方式**：从官方网站给出的应用宝（腾讯应用商店）页面读取包 MD5（`00bcfb66f8223ba9536ee3777d5c9db6`）与体积（40,681,819 字节），从腾讯 CDN 下载同名包；下载后 MD5、体积与商店记录完全一致，签名证书 `CN=YZune`。
- **研究方式**：仅在雷电模拟器 LDPlayer14 中安装并逐屏操作，未登录任何学校账号，未输入任何凭据，未抓取其私有接口或代码。
- **目的**：学习其「从教务导入课表」的信息架构与异常处理，用于改进本应用（桃课）。**不复制其代码、资源、学校库或私有格式。**

---

## 一、观察到的导入流程

1. **入口**：空课表首页中央有「无课表，通过教务导课 / 一键导入」；首次进入弹出「一键导入完整课表」，三选一：从教务导入 / 从分享口令 / 从文件导入。
2. **选学校**：A–Z 索引 + 收藏 + 全称搜索；列表右侧直接标注教务系统类型（如「正方教务」），没有标注的学校仍可选择。
3. **直达真实系统**：选中学校后打开内置浏览器，URL 直接指向该校教务登录页，而不是教务处首页。实测两例：
   - 示例树维高校（如清华大学等试点样例） → `example.edu.cn/eams/HomeExt.action`（移动版 EAMS 登录页，学校视觉主题）；
   - 安康学院 → `jwxt.aku.edu.cn/jwglxt/xtgl/login_slogin...`（正方教务 v9.0 登录页）。
   - 注：本机直接请求 `https://example.edu.cn/eams/HomeExt.action`（含多种手机/微信 UA 与 Referer）均返回 HTTP 403，无法确证其是否经过代理或缓存。因此本应用**未**把该地址写入学校目录，继续使用公开可访问、已在应用内验证的 `https://jwxt.example.edu.cn/eams/localLogin.action`。
4. **浏览器内引导**：顶部常驻横幅「请找到个人/学期课表」（可展开）；底部提供「电脑模式 / 横屏模式 / 打不开」；右下角悬浮「导课」按钮。
5. **先选写入方式再解析**：点「导课」先弹出「覆盖当前课表 / 新建课表再导入 / 取消导入」，然后才解析当前页面。
6. **失败处理**：解析失败时横幅变红「尚未找到有效课表」，对话框提示「请进入完整的个人课表页面后重新导课」，保留浏览器与会话，并提供官方 QQ 反馈入口。
7. **成功后**：提示检查缺课与时间，再由用户确认。

## 二、与本应用 v2.2.2 的对照

| 环节 | v2.2.2 现状 | WakeUp 做法 | 本轮结论 |
|---|---|---|---|
| 登录方式 | 内置受控浏览器，用户自行登录，不保存密码 | 相同 | 继续坚持 |
| 失败后会话 | 保留 WebView + 页内错误提示 | 保留 WebView + 红色横幅 | 采纳「状态横幅」表达 |
| 页面适配 | 仅移动 UA | 可切电脑 UA、横屏 | **采纳**：电脑模式 / 横屏模式 |
| 帮助出口 | 「浏览器打开」+ 失败文案 | 「打不开」汇总帮助 | **采纳**：帮助对话框 |
| 入口准确性 | 部分学校入口是教务处首页，按钮仍写「登录教务系统」 | 学校库只收录已知系统入口 | **采纳**：按 URL 判断并改写按钮/提示 |
| 写入时机 | 先提取到预览、人工校正后写入 | 先选覆盖/新建再写入 | 保留我们的预览模式（更安全，避免错误导入覆盖） |
| 分享口令 | 无 | 私有分享码格式 | 不逆向、不兼容，避免依赖闭源格式 |
| 学校库 | 教育部 2741 所 + 公开教务处地址 | 约 1200+ 所导入向学校库 | 保留完整目录，补真实系统入口需持续公开核验 |

## 三、本轮落地的改动（v2.2.3）

1. **页内步骤横幅**：默认蓝色「请找到个人 / 学期课表」+ 三步操作提示；识别失败时同一位置变红「尚未找到有效课表」并显示具体原因。
2. **电脑模式**：切换桌面版 Chrome UA 并刷新，适配只在电脑版渲染的教务系统。
3. **横屏模式**：切换为横屏，宽表课表更易查看；退出页面自动恢复原方向。横屏时自动收起地址栏（底部「地址」可展开），把有限高度让给网页。
4. **全屏浏览**：浏览器打开时隐藏应用底部主导航，关闭后恢复。
5. **打不开帮助**：汇总「电脑模式 / 系统浏览器打开 / Excel-PDF 导入或提交适配申请」三条出路，并可复制当前链接。
6. **入口文案校准**：入口 URL 不含登录/系统特征（`login`、`jwglxt`、`eams`、`jwxt`、`urp` 等）时，按钮改为「打开教务入口」，并提示用户进入后先点「教务系统 / 学生登录」。

## 四、仍未解决 / 后续

- **真实账号课表抓取**仍需学校本人账号实测，本应用不会保存或上传密码。
- 对「入口是教务处首页」的学校，需要长期补充并公开核验真实系统登录地址；在此之前应用会如实提示，不冒充登录页。
- 不实现 WakeUp 的私有分享口令格式。
