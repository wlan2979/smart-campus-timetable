## 一、实机验收发现并修复的问题（6 项）

### 1. 天气页三个操作按钮在窄屏被截断（第三个按钮无文字）
- **现象**：`刷新真实天气 / 切换城市 / 自动定位` 三个按钮排在同一行，720px 宽度下第三个按钮被裁掉，只剩空白圆角矩形——正是用户反馈的「按键上没有文字」同类问题。
- **修复**：改为 `FlowRow` 自动换行，「自动定位」完整显示在第二行（截图 07）。

### 2. 受控教务浏览器顶栏标题挤压换行、与按钮重叠
- **现象**：标题「受控教务浏览器（绝不记录密码）」在「关闭 / 浏览器打开 / 提取课表」之间被压成三行并互相遮挡。
- **修复**：顶栏标题精简为「教务网页」单行；「不保存、不拦截、不上传教务密码」改为 WebView 上方独立提示行（截图 06）。

### 3. 节假日页多处布局被压扁
- **现象**：①顶栏标题「法定节假日与学校校历」换行截断；②「同步国务院安排」按钮被挤成竖排圆形；③「连续假期节前提醒」标签被压成一字一行。
- **修复**：标题精简为「节假日与校历」；年份切换与同步按钮拆为两行，同步按钮整行显示；提醒选项改用 `FlowRow` 换行（截图 17、19）。

### 4. 作息规则编辑页标题与底部操作栏被截断
- **现象**：①标题两行换行遮挡学期副标题；②「每 3 节 / 每 4 节」「12 节 / 14 节」选项挤压换行错位；③底栏「存为模板」文字被截掉一部分。
- **修复**：标题改为单行「作息规则编辑」；大课间频率与当天节数两组选项改用 `FlowRow` 换行；底栏三个按钮使用紧凑内边距，文字完整显示（截图 13）。

### 5. 国务院节假日数据源在国内网络超时（真实缺陷）
- **现象**：模拟器点击「同步国务院安排」返回 `timeout`。实测本机到 `raw.githubusercontent.com` 15 秒不可达（host 与模拟器同样失败），而 `holiday-cn` 是多数国内用户无法直连的 GitHub raw 地址。
- **修复**：仅当使用默认 GitHub raw 模板时，依次追加同仓库同文件的 jsDelivr CDN 镜像（`cdn.jsdelivr.net` / `fastly.jsdelivr.net`）作为后备；自定义数据源地址时不追加，保持用户配置优先。404（年份未公布）不重试，直接如实提示。
- **实测结果**：修复后同一网络下同步成功——`2026 年国务院安排：合并为 7 个完整法定假期区间、6 个调休工作日条目`，数据来源显示为国务院办公厅通知原文链接（截图 19）。

### 6. 小组件中心预览与真实组件不一致
- **现象**：真实「今日概览」桌面小组件包含天气与下一节状态，但应用内预览只显示日期与课程。
- **修复**：预览补齐「天气 + 下一节状态」两行，与桌面组件一致；一键固定失败时的手动步骤对话框标题改为「手动添加小组件步骤（以小米 / Redmi 为例）」，不再让用户误以为是设备品牌识别结果（截图 14、21）。
