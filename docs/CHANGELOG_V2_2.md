## 一、全部操作按钮补齐文字并统一形状

- **问题**：上一轮仍有返回箭头、上一周/下一周、上一年/下一年、搜索清除、关闭等纯图标按钮没有文字说明。
- **改动**：全仓 `IconButton` 清零（`grep IconButton` 无结果）。所有操作入口统一为 Material 3 `TextButton`/`Button`（图标 + 可见文字）：
  - 各页面顶栏「返回」：图标 + 「返回」；
  - 课表「上一周 / 下一周」，节假日「上一年 / 下一年」；
  - 学校搜索「清除」、受控浏览器「关闭」；
  - 课程详情「编辑 / 删除」、学期「切换 / 删除」、校历覆盖「删除」、作息「撤销」等；
  - 仅纯装饰图标保留 `contentDescription = null`，不再存在无文字的可点击图标按钮。
- **形状**：统一使用 Material 3 默认圆角与高度，不再混用圆形 IconButton 与胶囊形按钮。

## 二、导入课表直达学校教务处（参考 WakeUp 课程表）

- **问题**：选择学校后打开的是学校官网首页，而不是教务处/教务系统，无法直接登录导入。
- **改动**：
  - 新增 `android/data/src/main/assets/school_academic_urls.json`（学校代码 → 教务处/教务系统网址）。
  - **真实校验流程**：以公开高校官网域名数据为基础，逐一请求 `jwc.` / `jw.` / `jwxt.` / `jwgl.` / `jiaowu.` 等常见教务域名及官网导航中的「教务处」链接，仅保留 **HTTP 可访问且页面标题/正文含「教务处 / 教务」** 的地址；官网首页、无关页面一律丢弃。
  - 选择学校后：已收录学校**直接打开该校教务处/教务系统登录页**；未收录学校改为「学校名 + 教务处 + 课表」检索结果（仍不是学校官网首页），并在界面中明确说明，可随时在「网页链接」粘贴实际教务系统地址。
  - 示例树维高校（如清华大学等试点样例）已指向真实教务处 `https://jwc.example.edu.cn`。
  - 遵循安全红线：受控 WebView 由本人完成学校登录与验证码，**不保存、不拦截、不上传教务密码**。
- **覆盖面**：已收录 **1033 所**高校（以 `school_academic_urls.json` 实际条目为准，含 2741 所目录中的 37.7%）；其余学校使用检索兜底。教务处地址会随学校网站调整变化，App 不做虚假承诺。

## 三、天气城市扩充至 2154 座

- **问题**：上一轮 275 座仅覆盖地级市，县级市/县城区仍搜不到。
- **改动**：基于 GeoNames 中国数据集（CC BY 4.0）重新生成 `ChinaCityPresets.kt`：
  - 收录全部省级/地级行政驻地与 **县级行政驻地**（PPLA / PPLA2 / PPLA3）及人口 ≥15 万的城镇点，去重后 **2154 座**；
  - 中文名优先取 GeoNames 中文别名并统一转换为简体，缺失时从同级行政记录补齐；
  - 坐标全部校验在中国范围（纬度 18–54、经度 73–135），名称唯一。
- **验证**：`CityPresetsTest` 提升为「≥2000 座」，并新增涿州、迁安、昆山、义乌、常熟、仙桃、济源等县级城市断言。

## 四、学校列表按省份分组，不再区分本科/高职

- **问题**：学校栏用「本科 / 高职」筛选区分，不符合实际查找习惯。
- **改动**：移除本科/高职筛选芯片与列表中的层次标签；学校列表按 **省份分组显示**（组头显示省份与数量），仍保留省份筛选芯片与关键词/拼音搜索。统计卡片改为「覆盖 N 个省份 · 已配教务入口 N 所」。
- 数据库仍保留 `schoolLevel` 字段用于后端目录与统计，但**界面不再按层次区分**。

## 五、桌面小组件聚合多项信息

- **问题**：单个小组件只显示一类信息。
- **改动**：「今日课程」小组件升级为「**今日概览**」，一个组件同时显示：
  - 日期、星期与教学周；
  - 实时天气（城市 + 温度 + 天气现象，来自本地缓存真实气象数据）；
  - 下一节课名称、倒计时与时间地点（正在上课时显示距下课时间）；
  - 今日课程时间与教室列表（超出显示剩余节数）。
- 组件名称与描述同步更新为「桃课 · 今日概览（课程+倒计时+天气）」，其余三个小组件保留。
