## 4. 天气来源删除手机系统天气 + 扩充 Open-Meteo 城市

- **删除系统/厂商天气**：移除 `SYSTEM_VENDOR` 数据源、`DeviceWeatherCapabilityDetector`、`SystemVendorWeatherProvider`、设置页设备检测卡片与「打开手机自带天气」按钮、Manifest 中各厂商天气包可见性声明。旧版本已保存的 `SYSTEM_VENDOR` 设置升级后自动回落 `OPEN_METEO`。
- **城市数量扩充**：新增 `ChinaCityPresets.kt`，离线速查表由 20 座扩充至 **275 座地级及以上城市**（坐标取自 Open-Meteo Geocoding / GeoNames 公开数据，CC BY 4.0），**包含苏州**。城市选择弹窗支持输入即时本地筛选，未命中时提示改用联网搜索。
- **联网搜索修复**：Open-Meteo 地理编码请求增加 `countryCode=CN`、`count=20`，并对「苏州市」自动尝试去掉「市」后缀；避免同名海外城市与「搜不到」问题。
- **验证**：新增 `CityPresetsTest`（2 项）校验城市数量 ≥250、包含苏州等代表城市、坐标在中国范围内、名称无重复；`assembleDebug` 与全量单测通过。

## 6. 修复导入课表时无法跳转浏览器登录

- **根因**：
  1. 未填写网址时点击「受控浏览器登录」会以 `https://` 作为初始地址，WebView 显示空白页；
  2. 未适配学校即使目录中有官网入口也被禁止打开；
  3. WebView 缺少多窗口/弹窗处理，部分教务门户无法正常渲染；
  4. 无法跳转系统浏览器。
- **修复**：
  1. 打开前校验地址：优先使用输入框，其次自动回填所选学校官网；两者皆空时给出明确提示，不再打开空白页。
  2. 未适配学校只要目录中有官网地址，也允许打开受控浏览器自行登录查看（仍如实标注「暂未适配」）。
  3. WebView 增加 `WebChromeClient`、关闭多窗口拦截、禁用本地文件访问；按返回键优先网页回退。
  4. 顶栏新增「浏览器打开」，通过系统 `ACTION_VIEW` 用默认浏览器打开当前教务页面。
  5. 选择学校时自动把官网地址填入网页导入输入框。
- **验证**：`assembleDebug` 通过；静态核对 WebView 设置与导航回调。

## 诚实说明

1. **无真机/模拟器**：本环境未连接 Android 设备，也没有 Emulator 系统镜像。图标实际桌面效果、受控浏览器在各校真实门户的登录与提取、浏览器跳转、按钮排版需在真机安装后确认；本轮仅完成编译、单测与资源/清单校验。
2. **示例树维高校（如清华大学等试点样例）**：仅完成目录录入与官网上联，未用真实账号验证其教务系统课表结构，因此保持 `verified=false`。
3. **城市坐标**：275 座城市坐标来自公开地理编码数据，已做范围与重名校验，但不排除个别城市取到邻近驻地坐标；如发现偏差可直接修改 `ChinaCityPresets.kt` 并重新构建。
4. **系统天气删除**：旧设置自动回落 Open-Meteo；不会读取任何厂商天气数据。
