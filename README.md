# 桃课 · 智能校园课表（Taoke · Smart Campus Timetable）

一款面向中国大陆普通本科院校、高职院校学生的 **Android 原生智能课表应用**（Kotlin + Jetpack Compose + Material Design 3 + Room + Hilt + Jetpack Glance）与配套 **Spring Boot 云同步后端服务**。**当前版本 v2.2.9（versionCode 13，后端 2.2.9）**：面向全国所有高校通用升级「一大节 = 两小节（如 45×2 + 5 = 95 分钟）」智能识别、自动连堂合并（`1-1` → `1-2`、相邻两门同课 `1-2` + `3-4` → `1-4`）及导入前作息快捷/自定义校准；同时将 Android 与后端高校选择目录全面升级为严格按拼音 A–Z 升序排列与首字母快捷定位（详见 `docs/CHANGELOG_V2_2_9.md`）。

> **核心工程原则**：本地优先、功能真实性优先、隐私安全合规——游客无需登录即可使用全部核心功能；严禁硬编码密钥或使用假接口冒充真实服务；绝不保存、拦截或上传学校教务系统密码。

## 核心功能亮点

1. **智能周课表与学期管理**：周一至周日网格视图、跨节显示、当前周与当日高亮、上下周切换与一键回本周；支持普通/单周/双周/自定义周、按星期差异化作息、独立保存临时调课/停课/换教室/换教师（不破坏原规则）、多维课程冲突检测与并排防重叠展示。
2. **作息时间规则编辑器（第二轮新增）**：不再逐节手动改时间。按「统一规则」设置每节时长、小课间、每 N 节大课间、午休、晚间休息与上午/下午/晚间起始时间，系统自动推算整天节次；支持单节差异化时长与任意节间自定义休息、按星期独立作息、周日无课；内置普通/夏季/冬季/周末四套可编辑模板并支持另存与一键切换；修改后实时预览，可应用至指定星期或整学期，并联动重算闹钟、体育课天气与桌面小组件（保留全部临时调课）。
3. **多渠道课表导入与人工校正**：
   - 内置 **教育部《全国普通高等学校名单》2741 所大陆高校目录**（支持全称/简称/别名/拼音/拼音首字母检索），完全离线可搜索；**v2.2.0 起学校列表按省份分组展示，不再区分本科/高职**；支持远程热更新，扩充学校无需重新发版。
   - **v2.2.0 教务处直达**：内置 1033 所高校**真实教务处网址**（经公开访问校验，标题含「教务处/教务」），选择学校后可一键打开该校教务处或教务系统登录页；未收录学校自动改为「学校名 + 教务处 + 课表」检索，不再跳转学校官网首页。
   - 可扩展 `SchoolAdapter` 教务适配器框架（正方、强智、新 URP、旧 URP、树维 EAMS 五类通用适配器；未经实网验证学校一律诚实标注 `verified=false` 并引导受控浏览器提取或 Excel/PDF 导入）。
   - Excel 导入（Apache POI `.xls` + 原生 OOXML `.xlsx` 支持列表型与周网格合并单元格）。
   - PDF 导入（PDFBox-Android 文本提取 + 扫描版 PDF 自动渲染并调用 Google ML Kit 本地中文 OCR）。
   - 网页链接导入（自动识别 UTF-8/GBK 编码、登录态与 JS SPA 探测 + 受控 WebView 辅助登录与一键清除会话）。**v2.2.0 修复**：选择学校后直接进入**该校教务处/教务系统**（不再打开学校官网首页）；未收录直达地址时自动准备教务处检索，受控浏览器新增「浏览器打开」跳转系统浏览器、返回键网页回退与弹窗/多窗口兼容。**v2.2.2 修复**：学校卡片区分「教务系统入口 / 教务处网站」，优先直达真实登录页；提取失败不再关闭浏览器，改为页内提示下一步；解析器按展开后的网格识别跨行/跨列课表，同一页面只取最像课表的一张表格，教务处首页文字不再被误识别为课程。**v2.2.3 体验**：受控浏览器全屏化并常驻步骤横幅，新增电脑 UA 模式、横屏模式（自动收起地址栏）与「打不开」帮助；入口不是登录页时按钮如实改为「打开教务入口」。
   - 统一导入预览工作台，支持逐条人工修改、补录与实时冲突预警。
4. **双模式智能上课闹钟**：支持普通通知与真正闹钟（响铃页 + 系统铃声 + 震动）自由切换、自定义提前时间与单课覆盖、上课与下课提醒、一键静音今日、重启/改时/时区/更新自动恢复，以及 Android 12+ 精确闹钟权限缺失时的自动降级方案。**第二轮已彻底移除不可靠的 TTS 语音播报**（原因与决策见 `docs/CHANGELOG_V2.md`），通知、铃声、震动与上下课提醒全部保留。
5. **体育课智能天气提醒**：自动识别体育类课程（支持手动切换）。**v2.1.0 已按要求删除手机系统/厂商天气入口**，仅保留真实公开气象接口：默认免密钥 **Open-Meteo**（内置 **2154 座**城市离线速查表：地级市、地区/自治州首府与县级市/县城区，输入「苏州」「涿州」「昆山」均可本地即时命中；也可联网检索全国城市），可切换和风天气 QWeather（需自备 Key）。针对降雨/降雪/雷电/高温/低温/AQI 6 项可调阈值，在前一天晚间与体育课当天课前合并推送提醒。
6. **法定节假日与大学校历覆盖**：自动拉取国务院办公厅年度节假日数据（记录来源/版本/更新时间，未公布年份明确提示不虚构）。**第二轮已改为按完整连续假期合并展示**：如「春节假期 2月15日—2月21日 · 共 7 天」，假日区间只生成一条节前提醒，不再逐日拆条；严格区分国家法定节假日、国务院周末调休与高校实际教学日历，学校校历覆盖（放假/照常上课恢复闹钟/按指定星期补课/停课）永远优先。
7. **游客模式、账号云同步与离线备份**：手机号 + 短信验证码登录（Spring Boot + PostgreSQL + Flyway + JWT），登录后安全合并本地游客数据并记录同步冲突；支持注销账号彻底删除云端数据；支持离线导出/校验预览/恢复版本化 JSON 备份包。
8. **四种 Jetpack Glance 原生桌面小组件**：今日概览（课程 + 下一节倒计时 + 实时天气）、下一节课倒计时、本周课表、天气与体育课提醒。**v2.2.0 起「今日概览」单个小组件即聚合日期/教学周、实时天气、下一节课倒计时与今日课程**；4 个 `GlanceAppWidgetReceiver` + `appwidget-provider` 元数据完整注册，应用内「桌面小组件中心」支持 `requestPinAppWidget()` 一键请求固定，不支持时提供小米/华为/荣耀/OPPO/vivo/三星/Pixel 等品牌图文添加指南；均直连本地 Room 数据库与缓存天气并在课表变更时自动刷新。
9. **v2.2.0 界面与易用性升级**：全应用操作按钮统一为**带可见文字**的 Material 3 按钮（返回、上一周/下一周、上一年/下一年、清除、关闭等不再只有图标）；学校列表按省份分组；天气城市扩充至 2154 座；今日桌面小组件聚合多项信息。
